# Bug & Feature Tracker

A simple Python command-line application for tracking software bugs and feature requests. This project helps users create, view, and manage bugs and features through an easy-to-use menu.
## Domain Lead

# Abdullah Faisal and Anila Irshad

## Features

- Create and record new bugs.
- Add feature requests.
- View existing bugs and features.
- Simple command-line interface.
- Beginner-friendly Python implementation.
- Git and GitHub version control.

## Technologies Used

- **Python** — application development
- **Git** — version control
- **GitHub** — source code hosting

## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/shoaibkhushi/Bug-Feature-Tracker.git
   ```

2. Open the project folder:

   ```bash
   cd Bug-Feature-Tracker
   ```

3. Run the Python file (replace `main.py` with your actual Python filename if different):

   ```bash
   python main.py
   ```

4. Follow the instructions displayed in the terminal.
